Maak je back-upsleutel aan

Met deze geheime sleutel versleutelt GitHub je databaseback-ups. De sleutel wordt alleen op dit apparaat gegenereerd met de cryptografisch veilige browserfunctie. Hij wordt niet naar GitHub, Supabase of een andere server gestuurd.

Belangrijk: bewaar de sleutel zelf in een wachtwoordbeheerder. Zonder deze sleutel kun je later geen databaseback-up ontsleutelen. Deel de waarde niet in deze chat of via screenshots.

De sleutel bevat 32 cryptografisch willekeurige bytes, gecodeerd als Base64. Dit past bij de GitHub Secret BACKUP_ENCRYPTION_KEY_BASE64.
